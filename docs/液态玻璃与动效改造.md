# 液态玻璃与动效改造汇总

> 基线：`f2bc2f7`（原项目 `feature/from-scratch-generation` 的末端）
> 分支：`feature/liquid-glass-ui`
> 范围：只改 `web/`（前端）与 `docs/`，后端逻辑、游戏生成链路、测试用例均未改动。

## 一、背景层

- 新增 `web/src/components/Backdrop.tsx`：整页背景图，固定定位、`object-fit: cover`、可关闭。
- 内置一张预设图 `web/public/backdrops/anime-sisters.jpg`；支持本地上传（转 dataURL，≤1.5 MB）、图片 URL、不透明度调节、`ken-burns` 极缓慢推移。
- 页面底色/压暗全部交给上层玻璃，背景本身不再加滤镜（避免“先透明再变黑”的二次问题）。

## 二、液态玻璃材质

- 每个玻璃容器三层结构：
  1. 元素本身：`backdrop-filter: blur(var(--glass-blur)) saturate(...) brightness(...)`；
  2. `::before`：深色底 `rgba(10,12,26, var(--glass-body))`（材质化时用它的 `opacity` 做渐压暗）；
  3. `::after`：斜向反射高光。
- 参数集中在 `:root` 的 `--glass-*` 变量：模糊 0–40px、饱和 100–250%、明暗 0.4–1.8、厚度 30–95%、亮边 5–80%。
- 覆盖范围：导航、导航胶囊、按钮、标签、分段控件、搜索框、首屏文案块、游戏卡片、面板、创作模板卡、页头、页脚、空状态、徽章、提示条、首页底部说明、表单控件。
- 设置在「液态玻璃 → 启用液态玻璃」可整体关闭，关闭后回到项目初版的纯色界面（含 `no-glass` 降级样式）。
- 修复过一个关键问题：拆分深色底时把 `background` 简写换成 `background-image`，没有重置 `background-color`，导致 `.panel`/`.game-card` 等被基础样式的实心底盖住、玻璃“失效”。

## 三、顶部导航胶囊

- 可拖动：指针拖动移动胶囊，松手吸附最近链接并跳转；拖动中禁止选中文字。
- **弹簧驱动**：`web/src/pill-spring.ts`（刚度 220 / 阻尼 26）驱动位置与宽度；换页 `animateTo`、拖动 `jumpTo`、松手后收敛。
- **形变**：拖动时按指针速度 `scaleX` 拉长、`scaleY` 压扁（实测可达 `matrix(1.5, 0, 0, 0.7, …)`）。
- **棱镜边**：`::before` 用 `conic-gradient` + `mask: exclude` 只留 1.6px 光谱细边，`::after` 用同一渐变 `blur` 做外晕；不依赖背景采样。
- 文字层级：当前项文字在胶囊**之上**（`z-index: 3`、`pointer-events: none`），拖动时文字原地不动，胶囊在下面滑过。

## 四、文字可读性

- 新增「文字颜色」设置面板，一个面板内可改：导航文字（自动/浅色/深色/自定义）、标题、正文、次要信息，另有「恢复默认文字颜色」。
- 导航文字「自动」：`web/src/nav-tone.ts` 采样背景图顶部条亮度，按玻璃厚度折算（`lum*(1-alpha)+14*alpha`，阈值 135）决定深/浅色。
- 页头/页脚/空状态/徽章/提示条/错误条补上深色底（此前它们的 `::before` 是透明，白字压在高亮背景上不可读）。
- 小字号说明统一用 `--muted` 并加 `text-shadow: 0 1px 2px rgba(4,6,16,.55)`；模式提示条文字提亮到 `#ffe2a1` / `#c9fbff`，`strong` 近白。
- 卡片细节：作者名金色 `#e8c06a`，官方标签淡紫，▶ 游玩数 `#9fd6ff`、♥ 收藏数 `#ff9ec7`。

## 五、动效

- **路由切换材质化**：不整页淡入淡出（会打断 `backdrop-filter`），而是 `html.glass-warming` 播放 520ms 动画：`--glass-blur` 由 0 长到设定值、各玻璃 `::before` 的 `opacity` 由 0.25 长到 1；顶部栏被显式排除，保持静止。
- **首屏入场**：标题 `line-rise`（上移 + `clip-path` 揭开）、说明 `blur-in`（80ms 延迟）、按钮组 `blur-in`（160ms 延迟）；动画只作用于玻璃容器内部的节点。
- **数字滚动**：`web/src/components/CountUp.tsx`，卡片的游玩数与收藏数从 0 滚到目标值。
- `prefers-reduced-motion` 下以上动画全部关闭或缩短。

## 六、设置页

- 入口在顶部导航「设置」。
- 面板：背景图片（预设/初版/上传/URL/不透明度）、液态玻璃（开关 + 五个滑杆）、文字颜色（导航/标题/正文/次要 + 恢复）、重置（恢复默认外观、只重置玻璃）。
- 偏好存 `localStorage` 的 `myol.prefs.v3`，只影响当前浏览器，不进服务端、不影响生成的游戏产物。

## 七、页面细节

- 首页底部说明与页脚改为与内容同宽的玻璃条；「初版原型说明」改为小胶囊标签。
- 站点图标 `web/public/favicon.svg`，消除 `/favicon.ico` 404。
- 空状态、拖动条、明暗默认值等按反馈修正（空状态补 20px 圆角、range 自绘轨道、明暗默认 1.00 不压暗）。

## 八、试过但已回退的方案

| 方案 | 为什么回退 |
|---|---|
| 首次进入欢迎页 | 用户要求删除 |
| 常驻玻璃底板（整块磨砂） | 观感是一个大磨砂块，被否决 |
| 预模糊图层 + `background-attachment: fixed` | fixed 在 `isolation`/`transform` 祖先内失效，卡片变成各自放大的错位图块 |
| 预模糊图层 + JS 逐元素偏移 | 滚动时背景追帧有一帧延迟，视觉上“追不上” |
| 面板折射环（6px） | 太窄看不出折射、加大又太明显，且每面板一次 SVG 滤镜开销不低 |
| 整页幕布过渡 | 整页先黑一下，体验更差 |

## 十一、切换异常的收尾修复（2026-11-21 晚）

这一轮把“切换页面时 UI 发白 / 先透明再变黑 / 出现白框 / 胶囊卡半路”全部定位并修掉，结论如下：

1. **真因是原项目自带的整页淡入**：`.page { animation: fade-in 250ms ease; }` 动的是 `.page` 的 `opacity`／`transform`。`.page` 是所有内容的祖先，动画期间后代的 `backdrop-filter` 全部失效（玻璃透明、无压暗），动画结束又一起生效（突然变实）。已改为 `animation: none`，页面内容直接出现。
2. **导航当前项不再自绘底色与边框**：原来 `.nav-links a.active` 有自己的紫色渐变底 + 边框，切换时会和胶囊叠成两个块、并随 `transition: all` 过渡出一圈框。现在指示块只由 `.nav-pill` 绘制。
3. **导航链接只过渡颜色**：`transition: all` 会把 `border-width/color` 一起过渡，切换时出现描边；改为 `transition: color, background-color`。
4. **胶囊改为布局动画**：`transform` 动画叠加滤镜会在合成器留下旧位置残影，现用 `left/width` + `contain: layout paint` + `overflow: hidden`，并去掉胶囊的 `backdrop-filter`。
5. **拖动判定重做**：指针事件从胶囊移到 `.nav-links` 容器，移动超过 8px 才算拖；阈值内交给链接正常导航，拖动结束后吞掉补发的 click。
6. **自愈校正**：每 600ms 校验胶囊与当前项是否对齐，偏差 >2px 自动重定位。
7. **深色底与元素同帧**：深色底从 `::before` 移到元素自身 `background-color`，避免新页面首帧“先出元素、后出伪元素”的透明瞬间。
8. **关闭材质化动画**：`html.glass-warming { animation: none }`，切换不再有半透明过渡。
9. 其它：空状态压暗浓度降到 0.55；页脚、首页底部说明、模板详情「示例试玩」说明、模板卡片等接入玻璃；文字颜色拆成导航/标题/正文/次要信息四类可配。
