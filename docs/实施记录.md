## 2026-11-21：胶囊折射补 RGB 色散 + 修坐标错位

- 色散：滤镜链改为 `feImage` → 三个 `feDisplacementMap`（base、R 用 1.22×、B 用 0.78×）→ 两个 `feColorMatrix` 分别只保留 R/B → 两次 `feBlend mode="screen"`，边缘因此出现红蓝色散。

## 2026-11-21：折射滤镜坐标 → 必须用元素局部坐标（0,0）

- 现象：加了 SDF 折射后，「没有边缘扭曲」；条纹测试里滤镜与无滤镜画面像素完全相同。
- 实测定位：把 `filter`/`feImage` 的 `x/y` 设成页面坐标（胶囊的 left/top）后，滤镜区域落到元素外 —— **带 offset 的版本与“无滤镜”截图 base64 完全一致**（`noneEqOffset = true`）；改回 `0,0` 后与无滤镜不同（`noneEqZero = false`），说明滤镜开始生效。

- 另核对原仓库源码：`liquid-glass.js` 只有一张 `feImage` + 一个 `feDisplacementMap`，**并没有 RGB 通道分离**；README 里的“RGB 边缘色散”是宣传文案，showcase 仅在文字里提到“色散彩边”，CSS 里没有实现。我们的版本反而额外加了 R/B 分离（三张位移 + 两次 screen）。
