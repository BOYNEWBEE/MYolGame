## 发现与处理

- `game.png` 截图仅显示导航和页脚：经浏览器自动化验证，`/games/:id` 路由在官方示例与发布后的游戏中均可正常渲染详情、iframe Canvas 与操作说明。截图异常可能是当时对应游戏 ID 不存在或页面尚未加载完成，未发现需要修复的代码缺陷。
- `node --test tests/` 在启用 TypeScript strip-types 时无法按目录加载，将 `package.json` 的 `test` 脚本改为 `tests/*.test.ts` 通配。
- 下载 HTML 时 Playwright 保存的临时文件名不一定带 `.html` 扩展名，测试改为校验文件内容包含 `<canvas` 与 `const CFG =`。
